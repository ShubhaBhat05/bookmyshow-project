# BookMyShow – Movie Ticket Booking System

A web-based movie ticket booking application that allows users to explore movies, view showtimes, reserve seats, manage bookings, and access digital tickets.

## Live Demo

[Visit the Live Website](https://bookmyshow-project-opal.vercel.app/)

## Features

- **Movie Management:** Movie details, trailers, reviews, and ratings.
- **Smart Seat Reservation:** Seat selection and live seat availability.
- **Booking Management:** Manage bookings and track payment status.
- **Admin Dashboard:** Manage movies, theaters, screens, and show schedules.
- **Movie Discovery:** Search, filter, trending movies, and recommendations.
- **PDF Ticket Generation:** Generate downloadable tickets with booking details and QR codes.
- **Email Confirmation:** Send booking confirmation emails with PDF tickets.
- **Booking History:** View previous bookings and download tickets.

## Tech Stack

- **Backend:** Python, Django, Django REST Framework
- **Frontend:** HTML, CSS, JavaScript
- **Database:** PostgreSQL
- **Background Processing:** Celery, Redis
- **Object Storage:** S3-compatible storage
- **Deployment:** Vercel

## Payment Workflow

The application uses a simulated payment workflow for testing bookings and ticket generation.

## Project Highlights

- Implemented movie discovery and seat reservation workflows.
- Integrated booking management and payment processing.
- Generated PDF tickets with QR codes.
- Implemented email delivery for ticket confirmation.
